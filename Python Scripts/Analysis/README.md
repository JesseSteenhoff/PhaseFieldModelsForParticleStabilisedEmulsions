# Python Script Overview: Analysis 

**Morphological_Analysis_PickeringEmulsions**: Analyses the morphologies of simulated 2D Pickering emulsions during their formation. It calculates profiles of the number of droplets, in addition to the average droplet diameter. Finally, it calculates the distributions of the droplet diameter in the system and visualises them as histograms. Requires ... as input data. 

**Morphology_Analysis_OffCritical**: Phase-field simulation that tracks the number and average diameter of droplets (Pickering emulsio) formed during off-critical phase separation. 

**Morphology_Analysis_Critical**: Phase-field simulation that tracks the characteristic length of the labyrinthine structure (bijel) formed during critical phase separation. 

**PickeringEmulsion_Coarsening_Profiles**: Analyses the profiles of the number and average diameter of simulated 2D Pickering emulsions. Requires [Profiles_OffCritical_Colloids](../../Data/Profiles_OffCritical_Colloids/) and [Profiles_OffCritical_NoColloids](../../Data/Profiles_OffCritical_NoColloids/) as input data. 

**PickeringEmulsion_Coarsening_Histograms**: Analyses the distributions of the average diameter in simulated 2D Pickering emulsions through histograms. Requires [Distributions_OffCritical_Colloids](../../Data/Distributions_OffCritical_Colloids/) and [Distributions_OffCritical_NoColloids](../../Data/Distributions_OffCritical_NoColloids/) as input data. 

**Profiles_Depth_STrIPS**: Analyses the morphology of simulated STrIPS bijels to generate depth profiles of the domain size. Requires [Profiles_Domains_STrIPS](../../Data/Profiles_Domains_STrIPS/) as input data. 

**Coarsening_Analysis_Powerlaw**: Analyses the morphology resulting from critical and off-critical phase separation to obtain the respective coarsening exponents. Requires [Profiles_OstwaldRipening_Critical](../../Data/Profiles_OstwaldRipening_Critical/) and [Profiles_OstwaldRipening_Offcritical](../../Data/Profiles_OstwaldRipening_Offcritical/)  as input data.
