# Data overview

Simulated morphologies that serve as the input data for the provided [Python Scripts](../Python%20Scripts/Analysis/). Details regarding the nature of each dataset can be found in the description of the corresponding script. 

**STrIPS Bijel 3D**: 3D morphologies of STrIPS bijels for different nanoparticle loadings (psi0). Morphologies are provided as .txt files that represent cross-sections (xy-plane) of the liquid and nanoparticle fields. The 3D morphology can be reconstructed from the cross-sections using imaging software ([Fiji ImageJ](https://imagej.net/software/fiji/downloads)).
